# Play Console — app access (reviewers)

Do **not** commit real passwords. Paste credentials only in Play Console → **App content** → **App access**.

| Field | Value |
|--------|--------|
| Login required? | Yes |
| Demo account username / email | `testing@gmail.com` |
| Demo account password | _(set in Play Console only)_ |
| Instructions | Sign in → complete or skip onboarding → Dashboard shows wallets. For **Bank alerts**: Settings → Bank alerts → enable SMS and/or Notification access → approve a draft in Inbox. **Delete account** is under Settings (do not use on the primary demo account if reviewers need persistent data). |

Update this table if the reviewer account changes.
