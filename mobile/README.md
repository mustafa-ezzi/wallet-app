# WalletTrails Mobile (Expo)

React Native app for WalletTrails — Phase 0–1: foundations + auth shell.

**Run / verify:** see [how-to-run-the-expo-app.md](./how-to-run-the-expo-app.md)

```powershell
cd mobile
copy .env.example .env   # set EXPO_PUBLIC_API_URL
npm install
npx expo start
```

Package id: `com.WalletTrails.app`
